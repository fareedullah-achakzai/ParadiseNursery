# Paradise Nursery

## Project Name
Paradise Nursery - Online Plant Shopping Application

## Project Description
Paradise Nursery is an online plant shopping application where users can explore different categories of houseplants, add plants to their shopping cart, manage quantities, and view their cart total.

## Main Features
- Browse different houseplant categories.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase and decrease plant quantities.
- Remove plants from the shopping cart.
- View the total shopping cost.

## Technologies Used
- React
- JavaScript
- CSS
- Redux Toolkit
- React Router
